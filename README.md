# 📦 Inventory Management System

A full-stack web application for managing products and categories
with real-time stock tracking, low stock warnings, and a
business dashboard.

Built as a portfolio project to demonstrate full-stack development
skills using React, Node.js, Express, and MongoDB.

## 📌 What This Project Is About

Many small businesses manage their inventory using spreadsheets
or paper-based systems. This application provides a simple and
clean web-based alternative.

With this system, a business owner can:

- Add, edit and delete products
- Organize products into categories
- Track stock quantities for each product
- Get automatic warnings when stock is running low
- See a dashboard overview of total products, stock value
  and low stock items

This project focuses on real business logic that is relevant
for small and medium-sized companies.
